## 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 词库覆盖不足 | 小岗位能力项漏抽 | JD 解析结果显式展示，不静默；词库单文件可增量 |
| 子串匹配误命中 | 证据判定偏宽 | V4 要求「命中且有原文」，闸门兜底；后续上分词 |
| 无 LLM，措辞不改善 | 用户觉得"就调了个顺序" | 已在 PRD/README 说明；v0.3 接模型 |
| 服务未鉴权 | 不能公网暴露 | 默认只监听 127.0.0.1 |
| 链接抓取有出网面 | SSRF / 被反爬 | 私网拦截 + 逐跳校验 + 超时/体积上限；登录墙提示改截图 |
| OCR 识别错字 | 分析结果偏差 | 结果先填输入框人工核对，不自动开跑 |
| 岗位池有状态 | 需要备份与数据过期 | 落 `data/jdpool.sqlite`；30 天自动退出候选池；只存 JD 不存简历 |
