为什么把档案排在 LLM 前：档案解决「说得对不对」，LLM 解决「说得漂不漂亮」。判断错了，写得好也没用。

## 二、用户档案（v0.2 核心）

档案不是自由文本，是**带出处的事实集合**：

```ts
type Fact<T> = { value: T; source: 'resume' | 'user_answer' | 'inferred'; evidence?: string; confidence?: number }

profile = {
  basics:   { years_experience, education: { degree, major, school, grad_year } },
  roles:    [{ title, company, period, industry }],
  skills:   [{ name, evidence: ['L12', 'L18'] }],
  projects: [{ name, actions[], results: [{ text, metrics[] }] }],
  gaps:     [{ requirement_id, status, question, answer? }]
}
```

规则：

1. `inferred` 字段只用于生成问题，**永不进简历**；
2. 用户回答先预览「将新增：…」，确认后写入，来源记 `user_answer` + 时间；
3. 匹配只有四态：`evidence` / `weak` / `gap` / `conflict`（硬门槛冲突）；
4. 档案默认只存浏览器 IndexedDB，支持导出/删除；什么时候上服务端库，见 `docs/DEPLOY.md` 的「什么时候需要数据库」。

与现有代码的关系：`collectEvidence` 的输出就是 `skills[].evidence` 的雏形，`missing_items` 就是 `gaps`。改动集中在新增档案结构、匹配矩阵、追问回填 UI，不动闸门。

## 三、Edit-OP 受限改写（v0.3）

沿用 IMPROVE-PLAN 的结论：LLM 只输出操作，不输出成稿。

| OP | 参数 | 确认策略 |
|---|---|---|
| `reorder` | line_id, to | 自动 |
| `term_align` | line_id, from, to | 自动（白名单内） |
| `rephrase` | line_id, before, after, intent | 用户逐条勾选 |
| `merge` | line_ids[], after | 用户逐条勾选 |

**在 IMPROVE-PLAN 之上补三条**：

1. **语义子集约束**：改后句的内容词集合 ⊆ 原句内容词集合 ∪ 白名单同义词。数字/实体/动词等级集合比对挡不住「为后续上线打下基础」这类暗加事实，内容词子集能挡。
2. **本地模型与部署形态冲突**：香港 2C2G 跑不了本地 LLM。先定形态（本地工具 / 在线服务），再定模型通道；在线服务默认用户自带 key，不做服务端托管 key。
3. **硬门槛解析结果要用户确认一次**：学历/年限从简历正则推断会错（非全日制、海外学历、空窗），不能直接下「不建议投递」的死结论。

## 四、评分口径（v0.1.2 已落地）

| 维度 | 计算 | 权重 |
|---|---|---|
| 事实一致率 | 通过断言 / 总断言 | 0.4，一票否决 |
| JD 对齐度 | 已回应 must 权重 / must 总权重 | 0.4 |
| 量化程度 | 含数字证据句 / 证据句 | 0.2 |

规则模式下事实一致率恒 100 是已知缺陷（改写器不产出新句子），所以它只作为 LLM 模式的保险，不作为规则模式的卖点。v0.3 改为 OP 级口径。

## 五、测试可信度（回应「测试有点假」）

| 现状问题 | 处理 |
|---|---|
| 用例全由实现者自写 | 引入真实样本：10–20 份用户提供的 JD/简历，人工标「该不该投、哪些是 must」，算一致率 |
| 权重/解析错误没有回归 | 本轮已加：权重来源、空格匹配、硬门槛、加权覆盖率 |
| 闸门用例是自造错稿 | 保留，但补「真实误杀」样本：合理改写被误判的 case 进回归集 |
| 只测内部函数 | 加黑盒用例：只打 HTTP，断言用户可见结果 |

## 七、风险

| 风险 | 应对 |
|---|---|
| 档案滑向「能力测评/性格画像」 | 只收岗位相关事实，明确写进 PRD 非目标 |
| PII 变多 | 本地存储优先、默认不落服务端、一键导出/删除 |
| 导入解析不准（PDF 排版/OCR 错字） | 结果进文本框供人工核对，不自动开跑 |
| LLM 改写暗加事实 | 内容词子集 + 操作级闸门 + 逐条确认 |
